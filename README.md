# Merry Christmas · 谷嘉耀

一棵能用**手势**控制的 3D 圣诞树 —— Three.js + MediaPipe Hands，纯前端，离线可跑。

## 玩法

打开摄像头，把手举到画面里：

- ✊ **握拳** → 装饰物飞回螺旋树形
- 🖐 **张开五指** → 全部散开，左右移动手掌可 360° 转动
- 🤏 **捏合** → 放大一张照片看，每捏一次翻下一张
- ↑ / ↓ → 上一张 / 下一张（手累了用键盘）
- U → 回到第一张
- G → 显示识别调试面板

手机打开时，请点右上角「…」→ 在浏览器打开（微信内置浏览器不给摄像头权限）。

## 技术

- Three.js r160（粒子系统 + UnrealBloom 泛光）
- MediaPipe Tasks Vision 手势识别（30fps 限流，5 帧投票防抖）
- 照片三级尺寸（1800 / 720 / 384），逐级替换保证清晰
